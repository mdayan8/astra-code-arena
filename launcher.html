Keep it running

Backups: hourly during a live round, every 6 hours otherwise, 30 kept. If the database is ever damaged it is restored from the newest good backup automatically.

Move to another computer

  1. Create a move package here and save it (Downloads or a USB drive). It holds every competition, question, student, result and upload.
  2. On the new computer: get the code, run start.sh, choose the package under "Moving from another computer", press Install. Everything is there, sized for that machine.
  3. Remove this computer as the host. On the same network, the new computer takes over the old address, so the student link stays the same.
